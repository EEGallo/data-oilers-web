# Data Oilers — Web Page
Sitio oficial de presentación de Data Oilers.

## Stack
Vite + React

## Desarrollo
Instalar dependencias y levantar el servidor local:

```bash
npm install
npm run dev
```

La landing queda disponible en `http://localhost:5173`.

Otros comandos:

```bash
npm run build    # build de producción
npm run preview  # previsualizar el build
```

## Deploy
GitHub Pages → rama `main`, carpeta raíz
